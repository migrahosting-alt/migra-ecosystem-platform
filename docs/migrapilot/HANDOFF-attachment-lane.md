## The gate, and its stated limit

`src/repositoryIntegrity.test.ts` now enforces: every source **module** is tracked, and no tracked
file imports a missing or untracked target (with `@/*` alias resolution — the brain-service gate
scans relative specifiers only and would not have caught this).

**Open, deliberately:** the tracking check skips **test** files, because your `uploadCeiling.test.ts`
cannot be committed until the exports above land. An untracked test does not run in CI — that gap is
real and stays open until your set lands, at which point the check should be widened to all sources
and the stronger gate (a typecheck in a clean worktree) can be added green.
